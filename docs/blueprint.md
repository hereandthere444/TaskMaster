# **App Name**: TaskMaster

## Core Features:

- Task Management: Allow users to create, edit, and delete tasks with descriptions and due dates along with divided section one section being goals(important) and other chores(not so important).
- Persistent Reminders: Implement a 'force' function that sends persistent notifications and reminders until a task is marked as complete.
- Force Mode: "Force" is a mode within app which is the presistant one that when enabled i.e. switched from simple to force mode it does the basic function force as mentioned in the second point along with sending notifications with motivational/taunting messages.
- AI-Powered Prioritization: Integrate an AI powered tool that analyzes task descriptions and due dates to suggest optimal scheduling and prioritization to get the task completed.

## Style Guidelines:

- Primary color: Dark teal (#008080) for a professional and focused feel.
- app theme should be like the pastel colour based.
- Secondary color: Light gray (#F0F0F0) for backgrounds and neutral elements.
- Accent: Bright red (#FF4136) to indicate overdue or high-priority tasks.
- Clean and simple layout with clear visual hierarchy for easy task management.
- Use clear and consistent icons to represent different task categories or actions.
- Subtle animations for task completion and priority changes.
- when starting or refreshing of the web app it must show the app logo with smooth animation and a motivational quote on self improvment.
